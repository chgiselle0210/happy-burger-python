# Happy Burger

Es una aplicación administrativa que desarrollaré como proyecto final del bootcamp Programación con Python nivel avanzado, que pertenece al certificado FullStack Developer de Tecmilenio.

El sistema administrará clientes, productos y pedidos desde la interfaz de la consola. Utilizará SQLite para almacenar la información, generará tickets de consumo en archivos de texto y contará con una interfaz web que desarrollaré con Flask para consultar pedidos con su número.

## Tecnologías

- Python
- SQLite
- Flask
- Pytest
- Git y GitHub
